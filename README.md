# SupportPilot AI Website

## Open locally
Double-click `index.html` or open it in any browser.

## Deploy
Upload `index.html`, `styles.css`, and `script.js` to Netlify, Cloudflare Pages, GitHub Pages, or any web host. No build step is required.

## Before launch
1. Business email is set to hello@supportpilot.ai.
2. Connect the lead form to Formspree, HubSpot, GoHighLevel, or your backend.
3. Add real Privacy Policy and Terms pages.
4. Confirm pricing and purchase your domain.

## Admin dashboard

Open `admin.html` after deployment. The included dashboard is a polished interactive front-end prototype with demo data. Before using it for real client information, connect authentication, a secure backend, and a database. Static GitHub Pages cannot securely protect admin data or API keys.
